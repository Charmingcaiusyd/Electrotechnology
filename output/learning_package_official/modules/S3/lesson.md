# 固定件与支撑 (Fixings and Supports)

本讲义为课程辅助材料。教材中的载荷、孔深、尺寸和安装示例只适用于其说明的产品/工况；不得把它们当成通用设计值。实际选型必须根据基材状态、载荷组合、边距/间距、产品认证与制造商说明，并按获批设计和现场程序复核。不得用未经批准的试拉或敲击方法替代规定检查。
## 3.1 常见固定件 (Common Fasteners)

### 学习目标
- 识别常用固定件类型及其用途
- 阐明不同固定件的工作原理
- 解释选择固定件时的主要考量因素

### 关键术语
- **扣件 (fastener)**: 永久连接两个物品或部件的装置
- **固定件 (fixing)**: 将可动部件连接至固定结构的装置
- **砖石螺丝 (masonry screw)**: 可直接旋入混凝土或砖的硬化螺丝
- **塑料膨胀管 (plastic expansion plug)**: 配合螺丝用于砖石墙的尼龙管
- **膨胀锚 (expansion anchor)**: 通过膨胀提供握力的锚栓，含锤击式、套筒式、楔形式
- **化学锚 (chemical anchor)**: 借助环氧或丙烯酸树脂固化的螺纹杆

### 原理
固定件通过机械咬合、摩擦、螺纹预紧或化学粘结等方式传递载荷。选择时评估功能、材料/产品属性、载荷大小与方向、安装条件和外观要求（Study Pack p.57）。教材关于钉长、导孔、锚栓尺寸/埋深的数字是特定示例，不能脱离产品、木材/砌体状态和设计要求照搬。化学锚的孔洞清洁、注胶、植入和固化步骤必须服从具体产品说明（p.58–59）。

### 受监督的实践工作流程
1. **评估基材**：确定是木材、砖石还是石膏板等。
2. **选型**：依据设备重量和安装环境，查阅制造商数据，选用适宜的固定件。
3. **钻孔**：在持证电工指导下，用正确钻头和模式（如冲击钻）钻孔。
4. **安装**：按工艺要求打入或旋入固定件；仅在产品或设计要求时，按指定值使用扭矩工具。
5. **记录**：标记所用固定件位置和类型，以备复核。

> ⚠️ 安全声明：所有电气安装必须遵守现行的 AS/NZS 3000 规定，并由持证电工实施监督。本培训资料仅提供通用知识，实际作业前务必核对最新标准与现场条件。

### 常见错误
- 在硬木中不评估木种、钉型和边距就直接钉入
- 砖石螺丝导孔直径、孔深或清洁方法未按产品要求
- 化学锚孔洞未清洁，树脂粘结强度骤降
- 套筒锚过度拧紧，崩裂混凝土
- 误在空心墙使用膨胀锚

### 检查问题
1. 选择固定件时，哪四个因素至关重要？
2. 为什么硬木打钉需要预钻孔？
3. 安装砖石螺丝时哪些孔参数和基材条件必须按产品说明确认？
4. 化学锚安装中，哪一步对粘结性能影响最大？
5. 过度拧紧楔形锚可能导致什么后果？

## 3.2 墙体/材料匹配 (Wall/Material Matching)

### 学习目标
- 根据墙体类型（实心砖墙、石膏板墙、木立柱墙）选择匹配的固定件
- 查读产品给出的基材、墙板厚度、安装方向和载荷条件
- 掌握立柱墙的构造和加强方法

### 关键术语
- **立柱墙 (stud wall)**: 由顶板、底板、立柱及横档组成的木框架墙体
- **石膏板 (plasterboard)**: 常见的墙/顶覆面材料，厚度和构造依项目而异
- **公斤力 (kgf)**: 力的单位；产品额定值还需核对测试工况和基材
- **螺纹石膏板锚 (threaded plasterboard anchor)**: 旋入墙板形成固定的空腔锚类型，承载依产品条件而定
- **翼型塑料锚 (winged plastic anchor)**: 带翼片，用于石膏板，轻载
- **金属空腔锚 (metal cavity anchor)**: 通过背面翼片扩大支承区域，需匹配墙板厚度和产品额定条件
- **肘节锚 (toggle anchor)**: 在空腔背面展开支承的锚具，适用性依基材、方向和额定数据确定
- **横档 (nogging)**: 水平安装在立柱间的木板或金属件，用于增加支撑点

### 原理
实心砖石、空腔墙板和木立柱墙的受力路径不同，固定件不能仅按名称或外观互换。墙板锚的额定值只适用于规定墙板、厚度、边距和受力方向；教材中的载荷示例及天花板折减值仅是教材/产品工况示例，不是通用公式。较重或有动态载荷的设备，应优先评估把载荷传入立柱、龙骨或经设计的横档（Study Pack p.59–60）。

### 受监督的实践工作流程
1. **墙体鉴别**：通过敲击声音或查看图纸，区分空心与实心墙。
2. **载荷评估**：核实设备质量、载荷方向、动态作用、支撑数量及设计要求。
3. **固定件选型**：先寻找可承载的结构支撑；若使用墙板锚，按具体产品额定数据和实际墙体条件核验，不以单一重量阈值代替设计。
4. **定位与安装**：避开石膏板边缘，确保锚固充分展开。
5. **验证**：按批准的检查/验收方案确认安装，不进行未经授权的试拉或加载。

### 常见错误
- 在空心石膏板墙上使用膨胀螺栓，无法咬合
- 螺纹锚未拧至充分展开，承重力骤降
- 把某个教材示例的吊顶折减值直接套用到其他锚具或工况
- 固定点过于靠近石膏板边缘，基材易破裂
- 灯具固定于素石膏板而无背后支撑

### 检查问题
1. 立柱墙通常由哪几部分组成？
2. 选择墙板锚时需要核对哪些产品和现场条件？
3. 为什么应尽可能把较大载荷传递到立柱/横档？
4. 为什么不能将教材中的天花板折减值当作通用系数？
5. 金属空腔锚上的防旋齿有什么作用？

## 3.3 支撑间距与承载 (Support Spacing and Load Capacity)

### 学习目标
- 解释支撑间距如何影响整体承载安全性
- 识别影响锚固系统承载能力的产品、基材、几何和载荷因素
- 识别动载荷对固定系统的特殊要求

### 关键术语
- **承载能力 (load capacity)**: 固定件可安全承受的力
- **剪切力 (shear force)**: 横向作用力
- **拉拔力 (pull-out force)**: 沿锚栓轴向拔出的力
- **动载荷 (cyclic load)**: 重复或振动的载荷，如电机启停
- **安全系数 (safety factor)**: 设计中用于处理不确定性的概念；具体取值须由适用标准/设计确定，不存在本课程可通用的固定比例

### 原理
固定件的性能由锚具类型、基材强度/状态、孔径和埋深、边距、间距、安装质量及拉力/剪力组合共同决定。教材说明化学锚不产生膨胀应力，某些产品可用于循环/振动载荷；不能据此得出化学锚对所有振动设备都是最佳选择。支撑布局应按系统设计、产品数据及载荷分配复核（Study Pack p.58–59）。

### 受监督的实践工作流程
1. **查阅数据表**：从制造商手册获取所用固定件在特定基材中的安全工作载荷（SWL）。
2. **校核设计**：按适用规范/工程设计考虑载荷组合、边距、锚点间距、基材和安全系数，不套用本讲义的固定比例。
3. **布置支撑**：依据设备底座、结构件、制造商数据和获批图纸安排锚点与支撑。
4. **考虑振动**：核对循环载荷等级、锁紧/防松方式和产品适用性，由设计或授权人员确认。
5. **验收**：按规定检查方法和记录完成验证，不擅自进行加载试验。

### 常见错误
- 低估振动影响，套筒锚在使用中松动
- 把加深钻孔当作可任意提高有效埋深的办法，未核对产品/设计要求
- 固定点过于集中，产生不平衡力矩
- 用于重载时仍采用轻载锚，安全裕度不足
- 未考虑混凝土强度等级，统一假定承载值

### 检查问题
1. 哪些产品和基材参数会共同影响套筒锚的抗拉表现？
2. 教材说明化学锚在什么条件下可能适用于循环/振动载荷？为什么不能据此说它在所有场合都优于膨胀锚？
3. 安全系数和锚点间距应依据哪些适用资料确定？
4. 若支撑间距过大，最可能发生哪种失效？
5. 为什么不能只用套筒锚直径或埋深来推断现场承载能力？

## 3.4 安装质量检查 (Installation Quality Check)

### 学习目标
- 执行安装后的目视和物理检验
- 识别常见的安装缺陷并采取补救
- 正确完成质量检查文档

### 关键术语
- **扭矩 (torque)**: 旋转力，用来控制螺栓预紧
- **拉拔测试 (pull-out test)**: 按指定方法评估锚固抗拉表现；测试可能破坏锚点或基材，是否实施须由设计/验收方案规定
- **目视检查 (visual inspection)**: 通过肉眼观察安装偏差
- **防旋 (anti-rotation)**: 防止固定件在孔内自转的结构，如齿形
- **固化时间 (curing time)**: 化学锚树脂完全硬化的时间

### 原理
安装后检查是确保固定系统长期可靠的最后一道防线。主要检查点：固定件型号是否正确、数量是否足够、位置是否准确、埋入深度是否达标、紧固扭矩是否适宜、基材有无裂纹、化学锚是否已完成固化。应在设备加载前完成全部检查。

### 受监督的实践工作流程
1. **初步目视**：检查固定件是否突出、歪斜，基材表面有无新裂缝。
2. **紧固检查**：仅在产品/设计要求时，使用合格且校准有效的扭矩工具按指定值检查。
3. **基材检查**：记录裂缝、崩边、空洞或其他异常，并交由设计/主管人员评估；敲击不能替代规定检测。
4. **化学锚专项**：按产品技术资料的温度/基材条件确认固化时间后再加载，不套用固定分钟数。
5. **记录与报告**：填写安装检查表，标注任何不合格项，并通知持证电工复核。

### 常见错误
- 完成后直接移交，未做任何检查
- 扭矩过大或过小，未按要求标定
- 化学锚安装后立即挂载，树脂未硬
- 在室外或潮湿环境使用非耐腐蚀固定件
- 对石膏板锚的防旋齿忽略检查，导致使用中旋转

### 检查问题
1. 为什么推荐使用扭矩扳手检查紧固件？
2. 如果发现固定件周围的混凝土有放射状裂纹，最可能原因是什么？
3. 化学锚安装后，为何必须等待指定的固化时间？
4. 防旋设计如何帮助维持固定件的稳定性？
5. 列举安装后至少应检查的三个方面。
