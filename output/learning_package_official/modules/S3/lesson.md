# 固定件与支撑 (Fixings and Supports)
## 3.1 常见固定件 (Common Fasteners)

### 学习目标
- 识别常用固定件类型及其用途
- 阐明不同固定件的工作原理
- 解释选择固定件时的主要考量因素

### 关键术语
- **扣件 (fastener)**: 永久连接两个物品或部件的装置
- **固定件 (fixing)**: 将可动部件连接至固定结构的装置
- **砖石螺丝 (masonry screw)**: 可直接旋入混凝土或砖的硬化螺丝
- **塑料膨胀管 (plastic expansion plug)**: 配合螺丝用于砖石墙的尼龙管
- **膨胀锚 (expansion anchor)**: 通过膨胀提供握力的锚栓，含锤击式、套筒式、楔形式
- **化学锚 (chemical anchor)**: 借助环氧或丙烯酸树脂固化的螺纹杆

### 原理
固定件通过机械锁紧、摩擦或化学粘结来传递载荷。选择固定件应综合评估：功能要求、刚度与强度、受力大小与方向、安装工艺、美观及成本（参见第57页）。例如，钉子用于木材连接，长度应穿透接收材的1/2至2/3；硬木务必预钻孔以防劈裂（第57页）。砖石螺丝需正确直径导孔，埋入30-45 mm才能保证最大拉拔力（第57页）。膨胀锚的承载能力取决于直径和埋深，且过拧会损坏基材（第58页）。化学锚适于动载与振动场合，安装时须彻底清洁孔洞（第59页）。

### 受监督的实践工作流程
1. **评估基材**：确定是木材、砖石还是石膏板等。
2. **选型**：依据设备重量和安装环境，查阅制造商数据，选用适宜的固定件。
3. **钻孔**：在持证电工指导下，用正确钻头和模式（如冲击钻）钻孔。
4. **安装**：按工艺要求打入或旋入固定件，使用扭矩扳手控制紧固度。
5. **记录**：标记所用固定件位置和类型，以备复核。

> ⚠️ 安全声明：所有电气安装必须遵守现行的 AS/NZS 3000 规定，并由持证电工实施监督。本培训资料仅提供通用知识，实际作业前务必核对最新标准与现场条件。

### 常见错误
- 在硬木中直钉导致劈裂（应预钻0.8倍钉径的孔）
- 砖石螺丝导孔直径不正确或深度不足
- 化学锚孔洞未清洁，树脂粘结强度骤降
- 套筒锚过度拧紧，崩裂混凝土
- 误在空心墙使用膨胀锚

### 检查问题
1. 选择固定件时，哪四个因素至关重要？
2. 为什么硬木打钉需要预钻孔？
3. 砖石螺丝的推荐埋入深度范围是多少？
4. 化学锚安装中，哪一步对粘结性能影响最大？
5. 过度拧紧楔形锚可能导致什么后果？

## 3.2 墙体/材料匹配 (Wall/Material Matching)

### 学习目标
- 根据墙体类型（实心砖墙、石膏板墙、木立柱墙）选择匹配的固定件
- 计算石膏板固定件的公斤力承载能力
- 掌握立柱墙的构造和加强方法

### 关键术语
- **立柱墙 (stud wall)**: 由顶板、底板、立柱及横档组成的木框架墙体
- **石膏板 (plasterboard)**: 常见的内墙覆面材料，12.5 mm厚
- **公斤力 (kgf)**: 用于表示固定件承载的力单位（1 kgf ≈ 10 N）
- **螺纹石膏板锚 (threaded plasterboard anchor)**: 尼龙或金属制，轻载（<10 kgf）
- **翼型塑料锚 (winged plastic anchor)**: 带翼片，用于石膏板，轻载
- **金属空腔锚 (metal cavity anchor)**: 带防旋齿和承载翼，载荷可达20 kgf
- **肘节锚 (toggle anchor)**: 最强的石膏板锚，载荷可达20 kgf，用于灯具、滑轨等
- **横档 (nogging)**: 水平安装在立柱间的木板或金属件，用于增加支撑点

### 原理
砖石墙依靠膨胀摩擦承载；石膏板墙则靠大面积撑开分散载荷。石膏板固定件的强度以公斤力表示（第59页）。例如，肘节锚的标称承载为20 kgf，但用于天花板时需乘以0.8。更可靠的方法是在天花板龙骨间加装横档，将灯具直接固定到横档上（第60页）。

### 受监督的实践工作流程
1. **墙体鉴别**：通过敲击声音或查看图纸，区分空心与实心墙。
2. **载荷计算**：称量待固定设备的重量，并考虑可能的动态冲击。
3. **固定件选型**：对于石膏板，如果设备重量超过10 kg，优先选用肘节锚或金属空腔锚；若可能，寻找龙骨或安装横档。
4. **定位与安装**：避开石膏板边缘，确保锚固充分展开。
5. **验证**：安装后试拉固定点，观察有无松动。

### 常见错误
- 在空心石膏板墙上使用膨胀螺栓，无法咬合
- 螺纹锚未拧至充分展开，承重力骤降
- 忽略天花板工况的0.8折减系数，导致过载
- 固定点过于靠近石膏板边缘，基材易破裂
- 灯具固定于素石膏板而无背后支撑

### 检查问题
1. 立柱墙通常由哪几部分组成？
2. 为什么肘节锚被认为是石膏板上最强的固定件？
3. 螺纹塑料锚的典型承载能力是多少？
4. 在天花板安装肘节锚时，为什么需将额定载荷乘以0.8？
5. 金属空腔锚上的防旋齿有什么作用？

## 3.3 支撑间距与承载 (Support Spacing and Load Capacity)

### 学习目标
- 解释支撑间距如何影响整体承载安全性
- 依据锚栓直径和埋深判断承载能力
- 识别动载荷对固定系统的特殊要求

### 关键术语
- **承载能力 (load capacity)**: 固定件可安全承受的力
- **剪切力 (shear force)**: 横向作用力
- **拉拔力 (pull-out force)**: 沿锚栓轴向拔出的力
- **动载荷 (cyclic load)**: 重复或振动的载荷，如电机启停
- **安全系数 (safety factor)**: 设计承载与极限承载的比值，通常取4:1

### 原理
套筒锚的承载：垂直安装时由直径决定；装于天花板时则由埋入深度主导（第58页）。振动设备（电机）会产生反复的拉、压力，化学锚因无膨胀应力且粘结力强，是理想选择（第59页）。支撑间距需确保各固定点受力均匀，避免个别过载。

### 受监督的实践工作流程
1. **查阅数据表**：从制造商手册获取所用固定件在特定基材中的安全工作载荷（SWL）。
2. **计算需求**：根据设备总重和可能出现的瞬时载荷，选择足够数量、安全系数≥4的固定件。
3. **布置间距**：将固定点均匀分布在设备底座周围，间距建议为锚栓直径的10-15倍（具体参照导则）。
4. **抗振处理**：对于电机等，首选化学锚，或在膨胀锚上添加防松螺母。
5. **测试**：安装后，由持证电工进行负载验证，检查有无移动。

### 常见错误
- 低估振动影响，套筒锚在使用中松动
- 顶棚安装时，未加深钻孔以增加埋入深度
- 固定点过于集中，产生不平衡力矩
- 用于重载时仍采用轻载锚，安全裕度不足
- 未考虑混凝土强度等级，统一假定承载值

### 检查问题
1. 套筒锚安装于天花板时，其拉拔力主要取决于什么？
2. 化学锚为何优于膨胀锚用于振动机械？
3. 工程设置中，固定件通常采用多大的安全系数？
4. 若支撑间距过大，最可能发生哪种失效？
5. 在垂直砖墙上安装重物，套筒锚的承载能力主要取决于它的哪项参数？

## 3.4 安装质量检查 (Installation Quality Check)

### 学习目标
- 执行安装后的目视和物理检验
- 识别常见的安装缺陷并采取补救
- 正确完成质量检查文档

### 关键术语
- **扭矩 (torque)**: 旋转力，用来控制螺栓预紧
- **拔拉测试 (pull-out test)**: 用专用仪器测试锚栓抗拉力的非破坏方法
- **目视检查 (visual inspection)**: 通过肉眼观察安装偏差
- **防旋 (anti-rotation)**: 防止固定件在孔内自转的结构，如齿形
- **固化时间 (curing time)**: 化学锚树脂完全硬化的时间

### 原理
安装后检查是确保固定系统长期可靠的最后一道防线。主要检查点：固定件型号是否正确、数量是否足够、位置是否准确、埋入深度是否达标、紧固扭矩是否适宜、基材有无裂纹、化学锚是否已完成固化。应在设备加载前完成全部检查。

### 受监督的实践工作流程
1. **初步目视**：检查固定件是否突出、歪斜，基材表面有无新裂缝。
2. **扭矩校验**：用校正过的扭矩扳手，按制造商推荐扭矩值抽查螺栓。
3. **敲击辨识**：用小锤轻敲锚栓附近基材，听是否有空鼓声。
4. **化学锚专项**：确认从注入至加载已超过固化时间，通常不少于30分钟（依产品而定）。
5. **记录与报告**：填写安装检查表，标注任何不合格项，并通知持证电工复核。

### 常见错误
- 完成后直接移交，未做任何检查
- 扭矩过大或过小，未按要求标定
- 化学锚安装后立即挂载，树脂未硬
- 在室外或潮湿环境使用非耐腐蚀固定件
- 对石膏板锚的防旋齿忽略检查，导致使用中旋转

### 检查问题
1. 为什么推荐使用扭矩扳手检查紧固件？
2. 如果发现固定件周围的混凝土有放射状裂纹，最可能原因是什么？
3. 化学锚安装后，为何必须等待指定的固化时间？
4. 防旋设计如何帮助维持固定件的稳定性？
5. 列举安装后至少应检查的三个方面。
