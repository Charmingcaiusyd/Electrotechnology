# Knowledge Card Edition

The student-facing release has been replaced by a course-wide flashcard study mode.

- Modules covered: S1-S10.
- Knowledge cards: 1,187.
- S1-S6 source-reviewed expansion: S1 138, S2 518, S3 130, S4 105, S5 93, S6 101 cards (about 3x their prior counts).
- Old 3,000-question exports, per-module quiz files, final exam, question-bank viewer, and seed-question exports have been removed from this release.
- Student entry: `html/index.html`.
- Offline data file: `html/cards-data.js`.
- Progress: browser-local, with JSON export/import.
- Review notes: `knowledge_cards_review.md`.

Course lessons and video scripts are supplementary study materials, not a replacement for current standards. S3 and S4-S6 learning materials were corrected for overgeneralized anchor values, unsafe meter demonstrations, component ratings, motor-start limits, and protection settings. See `knowledge_cards_review.md` for source mapping and review limits. Safety, compliance, calculations, and product-specific values must be checked against current local requirements before practical use.
