# 视频脚本：固定件与支撑——电工实操基础

## 第一部分：常见固定件

**视觉计划**：
- 展示钉子、砖石螺丝、塑料膨胀管、机械锚与化学锚，并标出各自的基材适用条件
- 木材连接剖面图，展示钉长、边距和木材状态如何影响劈裂与连接
- 砖石螺丝产品资料示例，强调导孔、孔深和清孔要求因产品而异

**解说词**：
大家好！本模块讨论电工工作中常见的固定件与支撑。选择时先确认基材、载荷方向和大小、设备是否振动，再核对固定件的产品资料和获批设计。木材连接不能只背一个钉长比例：木材种类、构件厚度、边距、钉型和连接要求都会影响选择；硬木或靠近边缘作业时，应按工艺要求评估预钻孔，避免劈裂。

砖石螺丝需要与规定的基材和钻孔工艺匹配。导孔直径、孔深、清洁方式和有效埋入深度都要查具体产品说明，不能把教材中的示例数值用于所有墙体。膨胀锚通过机械膨胀与基材作用；安装扭矩和边距应符合产品要求，过度拧紧可能损坏锚具或基材。

化学锚通过树脂粘结传递载荷，不产生同类机械膨胀应力；某些经认证产品适用于特定循环载荷条件，但不能笼统说它一定优于机械锚。孔洞清洁、基材状况、施工温度、固化时间和加载时机必须按具体产品技术资料确认。

**板书笔记**：
- 选型：基材、载荷、环境、产品认证与获批设计
- 木材连接：钉型、构件、边距与预钻要求按工艺确认
- 砖石螺丝：导孔、孔深、清孔、埋深按产品说明
- 化学锚：清孔和固化条件关键；适用性依产品及设计

## 第二部分：墙体匹配与选型

**视觉计划**：
- 展示实心砖石、石膏板空腔墙、木立柱墙及其受力路径
- 动画展示空腔锚在墙板背面展开，并提示墙板厚度与方向限制
- 用探测器、图纸和现场信息定位立柱/横档；演示发现异常时停止并报告

**解说词**：
不同墙体的受力路径不同，固定件不能只凭外观或名称互换。先辨认实心基材、空腔墙板或立柱墙，并确认设备载荷、安装方向、动态作用和可用结构支撑。石膏板锚的额定能力只适用于指定的墙板、厚度、边距、方向和安装方式。

对于较重或有动态载荷的设备，应评估能否把载荷传到立柱、龙骨或经设计的横档。若设计采用墙板锚，必须依据该型号的认证数据和现场条件校核，不能用一个“多少公斤”的通用门槛，也不能把天花板折减值套到其他产品。发现墙体构造不明、额定条件不满足或载荷路径不清楚时，暂停安装并请主管或设计人员确认。

**板书笔记**：
- 先识别墙体与载荷路径，再选固定件
- 核对墙板类型/厚度、安装方向、边距和产品额定条件
- 重载或动态载荷：评估立柱、龙骨或经设计的横档
- 不套用单一重量阈值或通用折减系数

**暂停提问**：
要在空腔墙安装设备，拿到墙板锚的额定值后，还要核对哪些现场和产品条件？

## 第三部分：支撑间距与承载

**视觉计划**：
- 展示拉力、剪力和组合载荷方向
- 图示基材、边距、锚点间距、埋深和安装质量对系统表现的共同影响
- 展示设备底座的锚点布局，并提示最终布置应依据产品数据及获批设计

**解说词**：
固定系统的表现不由锚栓直径或埋深单独决定。锚具类型、基材强度和状态、孔径、有效埋深、边距、锚点间距、安装质量，以及拉力和剪力的组合都会影响结果。设备振动还会引入循环载荷，需要确认产品是否适用，以及设计是否规定防松措施。

安全系数、锚点数量和间距必须依据适用标准、制造商数据和工程设计确定；不存在本课程可用于所有现场的固定比例。某些化学锚产品可能适用于特定循环载荷，但必须满足其认证条件，不能把“化学锚”本身当作振动设备的自动答案。资料不足或条件不匹配时，不猜测承载能力，交由授权人员复核。

**板书笔记**：
- 承载判断是系统判断：基材、几何、载荷、安装质量共同作用
- 区分拉力、剪力及其组合；考虑静载与循环载荷
- 安全系数、锚点数量/间距按适用标准、产品数据和设计确定
- 不凭锚栓直径、埋深或锚具类别单独推断承载能力

## 第四部分：安装质量检查

**视觉计划**：
- 依据检查清单核对型号、数量、位置、外观、基材和安装记录
- 展示按产品要求使用已校准扭矩工具的场景，并注明“仅在要求时”
- 展示化学锚产品资料中的固化条件，以及获批验收记录示例

**解说词**：
安装完成后，按批准的检查和验收方案确认固定系统。先核对固定件型号、数量和位置，再目视检查歪斜、突出、基材裂缝或崩边。只有产品或设计要求时，才按指定值使用合格且校准有效的扭矩工具。敲击听声不能替代规定的检查方法。

化学锚必须根据产品资料核实基材和温度条件下的固化时间，并在允许加载前保持未受载状态。不要套用固定分钟数。拉拔或其他加载测试可能影响锚点或基材，只有验收方案明确要求并由授权人员安排时才能实施。记录检查结果；发现异常时停止加载并报告主管/设计人员。

**板书笔记**：
- 检查：型号、数量、位置、基材状态与记录
- 扭矩/拉拔测试：仅依产品要求及批准的验收方案
- 化学锚：依产品条件确认固化及允许加载时间
- 发现异常：暂停加载、记录并报告

**暂停提问**：
如果发现锚栓松动但表面看不出基材破损，为什么不能只把它重新拧紧后就投入使用？
