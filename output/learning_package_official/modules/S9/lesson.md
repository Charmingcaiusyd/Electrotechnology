# 导管、线槽与布线安装 (Conduit, Wiring Enclosures and Installation)

## S9.1 导管系统 (Conduit Systems)

### 学习目标 (Learning Goal)
- 识别常用导管类型及对应等级（轻型/中型/重型），并了解其适用环境。
- 掌握UPVC导管的切割、去毛刺与溶剂粘接工艺。
- 理解导管敷设的基本走向原则和排水防潮要求。

### 关键术语 (Key Terms)
- UPVC导管 (Unplasticised PVC conduit) — 硬质PVC电工导管，通过溶剂粘接连接。
- 轻型椭圆导管 (light-duty oval conduit) — 灰色，仅限凿墙内暗敷。
- 中型导管 (medium-duty conduit, WS X1) — 灰色，用于地上无机械损伤处及混凝土板内。
- 重型导管 (heavy-duty conduit, WS X2) — 橙色，用于地下直埋。
- 溶剂水泥 (solvent cement) — 专用化学粘接剂，溶解PVC表面使其融合。
- 鞍形夹/管卡 (saddle/clip) — 用于固定导管的金属或PVC支架。
- 泄水孔 (weep hole) — 在导管低点钻的小孔，防止凝露积水。

### 原理 (Principle)
导管为电缆提供必须的机械保护，隔离外部环境，同时便于日后线路更换和扩容（第212页）。UPVC导管依靠材料本身的绝缘、耐化学腐蚀和轻质特性，成为住宅和商用最常见的布线方案。不同等级导管对应不同机械强度和安装环境（第212页）：轻型仅用于凿墙固定，中型适用于地上和混凝土板内，重型才有足够壁厚承受地下土壤压力和机械损伤。选择错误会引发安全风险，例如将灰色中型管埋入地下，根据AS/NZS 3000:2018该安装需满足更高保护类别（如增加覆盖或改用重型管）。正确的连接（溶剂焊接）保证导管内部的平滑连续，有利穿线；排水措施则防止冷凝水导致电缆绝缘劣化。

### 监督实操流程 (Supervised Practical Workflow)
1. **等级选择**：对照安装环境（地上/地下、腐蚀、紫外等）和电缆规格，按本地的布线规程选用导管颜色和壁厚。例如住宅二线供电导管最小使用50mm重型橙色UPVC，埋深600mm，且全线只允许一个预弯或定型弯头，弯头距计量箱不低于450mm上升（第212页）。
2. **切割与倒角**：佩戴侧面防护眼镜。使用导管专用剪或细齿钢锯垂直下刀。割后必须用导管铰刀或圆锉去除管口内部毛刺，再用倒角器或锉刀修出约0.5mm的倒角，防止牵引时割伤电缆绝缘（第212页）。
3. **溶剂粘接**：用干净棉布擦净管端和管接头内壁。均匀涂刷溶剂水泥于管端外表面和承插口内表面（勿过量，以免溶剂流入管内），立即将导管旋转1/4圈插入到位，并保持约15秒不动。粘接处初步强度已可支撑安装，但完全固化需24小时。操作时戴防护手套并在通风处进行，避免皮肤吸收和吸入蒸气（第212‑213页）。
4. **敷设要求**：已布导管应沿建筑线条平行水平或垂直走向，减量使用弯头和接线盒。所有导管系统未布线前必须先穿入直径≥2.5mm、两端留尾≥600mm的钢丝引线。管端暂时用软粘性胶泥封堵，防止进入杂物。接线盒、开关盒、插座盒等必须独立牢固固定，不得仅靠导管支承（第213页）。
5. **排水处理**：水平管段须朝终端或低点倾斜，坡度不小于1:200。在最低点朝下钻5mm孔，之后用冷镀锌漆防锈（金属管）或直接留孔（UPVC）。若为地下设施且自然排水不畅，则需在低点构筑砂石坑（排水收集坑），详见第214页图示。

### 常见错误 (Common Mistakes)
- 在地下直埋选用灰色中型UPVC，未执行附加保护措施，违反规定（第214‑215页）。
- 切割后未去除管口内部毛刺，导致穿线时电缆绝缘被割伤、留下隐患。
- 溶剂水泥涂抹不均匀或未旋转固定，造成虚接，后期可能松脱。
- 未按规范设泄水孔、低点积水，电缆长期浸泡易绝缘下降。
- 忽视当地供电机构关于服务导管弯头数量、管径及最小埋深的规定（如二线服务50mm、四线服务80mm）（第212页）。

### 检查问题 (Check Questions)
1. 灰色中型UPVC导管允许直接埋在混凝土板内吗？还需要附加什么条件？（答：可以，但需埋在混凝土板内，若为地上敷设则不能有机械损伤风险。）
2. 请说出切割UPVC导管后的三个基本处理步骤。（答：去除内部毛刺、倒角、清洁管端。）
3. 溶剂粘接时为什么要旋转导管1/4圈？（答：使溶剂水泥在结合面均匀分布，保证粘接紧密。）
4. 地下住宅二线供电导管的最小管径、埋深及允许弯头数是多少？（答：管径50mm重型，埋深600mm，弯头仅限一个预弯/定型弯。）
5. 导管低点为什么必须钻排水孔？（答：防止冷凝水或进入的雨水积聚，避免电缆长期受潮损坏。）

## S9.2 布线外壳 (Wiring Enclosures)

### 学习目标 (Learning Goal)
- 区分不同类型的布线外壳（包括各类导管、线槽、电缆托盘等）及其适用场合。
- 了解外壳的机械保护等级，能根据安装环境合理选择。
- 认识外壳安装对安全、可维护性和未来扩容的重要性。

### 关键术语 (Key Terms)
- 布线外壳 (wiring enclosure) — 统指电缆的机械保护壳体，包括导管、线槽、电缆托盘/梯架等。
- 钢性导管 (rigid steel conduit)
- 柔性导管 (flexible conduit) — 可弯的金属或PVC软管。
- 线槽/槽盒 (trunking) — 金属或PVC矩形槽，带可拆卸盖板。
- 电缆托盘/梯架 (cable tray/ladder) — 用于成束电缆支撑的开放结构。
- 保护等级 (protection category) — AS/NZS 3000定义的A、B等系统，反映不同的机械保护水平。

### 原理 (Principle)
布线外壳的首要功能是提供机械保护，防止电缆被外力损坏，同时隔离火焰蔓延，保护人身安全（第212页）。不同类型的壳体具备不同的保护能力：刚性金属导管耐冲击、防爆；柔性导管便于设备连接时的活动；线槽则适合分支回路多的场所，维护方便；电缆梯架、托盘适合工业厂房大量电缆的敷设，散热佳、扩容简便。规划时应预留30%左右的空间容量，以适应未来回路增加（第212页）。选择时要严格参照AS/NZS 3000:2018的相关条款，评估环境腐蚀性、紫外照射、动植物侵害风险（如沿海盐雾、霉菌、老鼠啃咬等）（第213‑214页）。错误选择会导致外壳提前锈蚀、松脱甚至电缆外露。

### 监督实操流程 (Supervised Practical Workflow)
1. **环境评估**：记录安装路径上的所有腐蚀源（化学品、盐碱土壤、沿海）、紫外线强度、可能的动植物活动（白蚁、霉菌、水果蝙蝠粪便等）及机械撞击风险（第213‑214页）。
2. **外壳选型**：根据评估结果，从合规材料表中选出对应产品，如室内干燥处可用PVC线槽；多粉尘潮湿车间可选镀锌钢管；地下穿过硫酸盐土壤必须用厚壁PVC或采取混凝土包裹的金属管（第213页）。
3. **安装准备**：按照所选系统的制造商说明和布线规程备齐管径、弯头、连接件、鞍形夹等。确保所有配件来自同一认证系列，避免材质不兼容产生的电化学腐蚀。
4. **铺设**：导管、线槽、梯架均应沿建筑线平行安装，避免横穿人流和货物移动区域。对开放式梯架，须保证搭接处牢固并设有防滑移设施。线槽内侧需去除所有锋利边缘，所有金属外壳需可靠接地连续性（第212‑214页）。
5. **可维护性与扩容**：在线路分支点和设备接线处设置足够尺寸的接线盒，使电缆弯曲半径不至于过小。预留的备用空间中不宜填充其他管道，并做好标识（第212页）。

### 常见错误 (Common Mistakes)
- 将仅适合室内使用的PVC线槽直接安装在户外日晒雨淋处，几个月即老化脆裂。
- 在化工厂酯类或芳香烃环境使用UPVC导管，导致管壁溶胀、软化（第213页禁忌）。
- 梯架跨接处仅用螺栓搭接而未加跨接线，导致接地连续性不可靠。
- 忽略动物侵害，如老鼠咬穿未密封的导管末端或缝隙进入，咬坏电缆。
- 密实填充导管，不预留未来扩容空间，后期加线只能重新开槽暗埋。

### 检查问题 (Check Questions)
1. 说出三种常用布线外壳的名称。（答：刚性钢导管、UPVC线槽、电缆梯架。）
2. 什么环境下不能使用普通UPVC导管？至少举出两种。（答：强紫外线直射且非“T”标志、存在酯类或氯代烃化学品的地方。）
3. 金属线槽安装时必须保证什么电气安全要求？（答：所有金属部分必须可靠接地，保持接地连续性。）
4. 在沿海地区，地上布线应避免使用哪种外壳材料？为什么？（答：普通钢管，因为盐雾腐蚀很快，可选用适当保护的镀锌或PVC。）
5. 为什么布线外壳要预留未来扩展空间？（答：便于日后增加回路而不必重做壳体，节省长期成本。）

## S9.3 弯管与支撑 (Bending and Support)

### 学习目标 (Learning Goal)
- 掌握导管弯曲的操作要求，避免褶皱、凹陷等缺陷。
- 熟记不同管径导管的鞍形夹支撑间距。
- 理解支撑结构独立固定的重要性。

### 关键术语 (Key Terms)
- 弯曲半径 (bend radius) — 为避免电缆绝缘受损，导管弯曲时的最小内半径。
- 定型弯头 (set/proprietary bend) — 工厂预制成型的直角或曲线弯头。
- 弹簧弯管器 (conduit bending spring) — 插入或套于导管外部的弹簧，辅助均匀弯曲。
- 鞍形夹 (saddle/clip) — 用于将导管固定于墙面、天花的金属或PVC夹件。
- 间隔支撑 (spacing of supports) — 两鞍形夹之间的最大允许距离，与自重和振动有关。

### 原理 (Principle)
弯曲过程如果操作不当，导管外侧受拉变薄、内侧受压起皱，会降低管体强度并阻碍穿线。正确的弯曲需使用专用弹簧或弯管机，保持均匀的弯曲角度，管内径不应小于电缆最大外径的6倍（以特定电缆为准，通用要求见AS/NZS 3000）。导管的支持间距过大会导致明显下垂，积累应力，可能使接头松动或断开。规范的支撑间距如：20‑25mm管水平敷设不超过900mm，32mm以上管不超过1.2m；垂直敷设均不超过1.2m。弯头、接线盒附近150mm以内必须双侧加鞍夹进行强化固定（第213‑214页）。这些要求确保整套导管系统稳固，避免机械振动或意外碰撞时的移位。

### 监督实操流程 (Supervised Practical Workflow)
1. **规划弯曲**：在布线图上标出所有弯点、接头盒位置，最大程度减少弯头数量，采用大弧度弯代替直角弯。对UPVC管，一般用配套的90°弯头，也可现场用弯管弹簧热弯，但需控制温度（参见产品说明）。
2. **准备工具**：依据管径选择适合的弯管弹簧（内弹簧或外弹簧）或弯管机。检查弹簧无锈蚀、变形。准备一角良好的工作台。
3. **弯曲操作**：将弹簧插入导管待弯部位（内弹簧）或套在管外（外弹簧），以均匀、连续的力量弯曲到所需角度后稍微回弹，确保无皱褶、无压痕。弯好后的导管内径不得明显缩小，内部应圆滑。不可出现死弯。
4. **鞍夹安装**：按照管径确定鞍夹间距。先在结构上定位标记，钻孔并装入膨胀胶塞（砖墙）或专用自攻螺丝（木/金属龙骨）。固定鞍夹时不得过度锁紧，避免将UPVC管压扁。确保鞍夹与导管之间无间隙，但又不过度变形。
5. **强化固定**：每个弯头、三通、接线盒的出入口150‑200mm内必须各装一个鞍夹；长直线段按最大间距均布置；垂直方向至少顶、底各一个夹紧点（见第213‑214页间距规定）。

### 常见错误 (Common Mistakes)
- 徒手弯曲UPVC管，未使用弹簧，导致管子明显压扁或产生尖锐折痕。
- 弯曲半径过小，使后面穿线困难，甚至划伤电缆芯线。
- 鞍夹间距过大，尤其长距离水平管下线缆重量导致导管明显“垂肚”，接头处受拉。
- 弯头附近未加双侧鞍夹，弯头成为整个管路的最弱点，轻微震动就松脱。
- 螺钉过度锁紧，将UPVC管夹出裂纹。

### 检查问题 (Check Questions)
1. 现场弯制20mm UPVC导管时应使用什么工具？（答：导管弯管弹簧，可为内弹簧或外弹簧。）
2. 25mm直径导管水平敷设时，鞍夹最大间距是多少？（答：不超过900mm。）
3. 弯头两侧的鞍夹应设置在什么位置？（答：距弯头出线端150‑200mm处，两侧各一个。）
4. 弯曲导管时如何才能避免内侧起皱？（答：使用合适的弯管弹簧，均匀施力，不可急弯。）
5. 垂直安装的导管，鞍夹间距应满足什么要求？（答：最大间距为1.2m。）

## S9.4 安装路径规划 (Installation Path Planning)

### 学习目标 (Learning Goal)
- 实地勘察并规划布管路径，减少交叉冲突和材料浪费。
- 识别环境中潜在风险并采取防护措施。
- 贯彻排水、防动植物和降噪的安装细节。

### 关键术语 (Key Terms)
- 路径规划 (route planning) — 综合考虑建筑结构、已有设备和电缆进出点，设计最短、最合理的管道路线。
- 交叉冲突 (clash) — 与水管、燃气管、通风管等其他建筑服务在空间上发生干涉。
- 排水坡度 (drainage slope) — 为保证管内积水自然流出，设定的倾斜方向与坡度。
- 补偿节 (expansion joint) — 长直线段中用于吸收热胀冷缩的专用接头。
- 端封/堵头 (plug/cap) — 施工期间封闭管口，防止异物进入。

### 原理 (Principle)
好的路径规划能显著提高安装效率、降低材料成本，并减少后期维护困难。导管走向应平行于建筑线，嵌入或紧贴结构面，避免横穿开阔区域。遇其他管线时，保持足够间距（一般水管300mm以上，燃气500mm以上），防止相互影响（如温度、泄漏）(第213页)。环境因素评估（紫外、化学物质、微生物、动物）贯穿选材和路径决策：阳光直射的墙体段，若用普通UPVC，须涂刷淡色丙烯酸漆；沿海段宜用PVC或不锈钢支撑件代替普通钢制（第213页）。此外，管道还需远离潜在的物理损伤源，如行车通道、重物堆场等。规划中还须纳入排水方案，任何可能凝露或进水的水平管段必须设坡度及泄水孔（第214页）。超长直线（通常超过6米）有必要增设补偿节，以吸收昼夜温差引起的伸缩。

### 监督实操流程 (Supervised Practical Workflow)
1. **现场丈量与制图**：用卷尺、水平仪测量实际建筑尺寸，标出配电盘、插座、开关等设备位置。在平面图上用不同颜色标清导管与其他管线的走向，找出所有交叉点。
2. **避开或穿越处理**：对于不可避免的交叉，规划好上下层次，确保电线管在最上方（若穿越热水管需加隔热措施）。在穿墙、穿楼层处开孔后必须用防火堵料密封。
3. **材料清单与分段**：由路径长度算出每段导管尺寸，列出所需直管、弯头、接头、鞍夹等。考虑运输与施工便利，将长段尽量设在易操作区域。
4. **实施注意**：先敷设主干管，后分支管。每敷一段即用管堵封口并绑扎临时标签。在规划的低点钻排水孔；长直线段若环境温度变化大，则插入膨胀接头（参考供应商说明书）。
5. **验收前检查**：所有管端仍封堵，目视管体无凹陷、鞍夹紧固，排水孔畅通。用线垂检查垂直度，水平管用气泡水平仪复核坡度。确认管路与图纸吻合，并拍照建档。

### 常见错误 (Common Mistakes)
- 直接沿最短线路“飞线”，导致导管斜穿墙壁、有碍观瞻和固定困难。
- 与其他管道距离太近，日后维修他管道时极易损伤电线管。
- 忽视排水坡度，部分管段形成“U”型积水袋，即使钻了泄水孔也可能因位置不对无效。
- 长距离直线未设补偿节，在夏季暴晒后导管弯曲翘起甚至撑脱接头。
- 对地下或其他不可见管段，未铺设为日后穿线预留足够大的接线盒，造成后期穿线卡死。

### 检查问题 (Check Questions)
1. 导管路径规划的首要原则是什么？（答：沿建筑线平行敷设，减少弯头和接头数量。）
2. 当导管必须穿越其他管道时，一般应保持多少最小间距？（答：水管≥300mm，燃气≥500mm。）
3. 什么情况下需要在直线管段加装补偿节？（答：管路总长超过6米且安装环境温度变化较大的场所。）
4. 如何防止施工期间杂物进入已安装的导管？（答：将所有开放管口用管堵或粘性胶泥暂时密封。）
5. 画出或描述导管如何设置排水坡度。（答：管段朝一个低点倾斜，坡度约1:200，最低点钻泄水孔。）
