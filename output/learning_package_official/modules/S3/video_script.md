# 视频脚本：固定件与支撑——电工实操基础

## 第一部分：常见固定件

**视觉计划**：
- 特写：各种固定件实物展示（钉子、砖石螺丝、塑料膨胀管、套筒锚、化学锚）
- 动画：钉子连接木材的截面，展示穿透深度
- 演示：砖石螺丝钻孔与旋入过程，旁边显示钻孔直径和深度标注

**解说词**：
大家好！在这个模块中，我们将探讨电工工作中必不可少的固定件与支撑。首先来看常见的固定件。在日常作业中，我们会接触到钉子、砖石螺丝、各类膨胀锚和化学锚。选择正确的固定件是安全安装的第一步。例如，连接木材时最常用的是钉子，但钉长必须足够——穿透接收材的一半到三分之二，而且硬木一定要预钻孔，否则会劈裂。

砖石螺丝可以直接旋入混凝土或砖块，但我们必须先钻好导孔，并保证埋入深度在30到45毫米之间，这样才有足够的拉拔力。膨胀锚通过膨胀挤紧孔壁来承载，从轻型的锤击锚到重型的套筒锚和楔形锚都有。重要的一点是：不要过度拧紧，否则会涨裂墙体。

对于振动大的设备，比如电机，化学锚是更好的选择。它们用树脂粘结，没有膨胀应力，但安装时孔洞必须彻底清洁，否则粘结力会大打折扣。

**板书笔记**：
- 钉子：长度 ½–⅔ 穿透；硬木预钻 0.8×钉径
- 砖石螺丝：导孔 = 螺丝直径；埋深 30–45mm
- 膨胀锚：勿过拧；承载看直径或深度
- 化学锚：清洁孔洞是关键，佩戴PPE，等待固化

## 第二部分：墙体匹配与选型

**视觉计划**：
- 剖面图：实心砖墙、空心石膏板墙、木立柱墙结构
- 动画：肘节锚在空心墙内展开的过程
- 演示：敲击墙面辨别空鼓，然后用铅笔标记，选择正确固定件

**解说词**：
不同的墙体需要不同的固定件。实心的砖石墙能使用膨胀锚，但石膏板墙是空心的，必须用特殊的锚固件。立柱墙由木框架和石膏板构成，最常见的固定点应该在底部的木龙骨上。如果只能固定在石膏板上，我们就要根据设备的重量来选择。

轻型的螺纹锚和翼型锚只能承受不到10公斤力，适合挂时钟或小灯具。对于较重的轨道灯或分电箱，要用金属空腔锚或肘节锚，它们可以承受20公斤力左右。安装在天花板上时，肘节锚的承载能力要打八折，更可靠的办法是在龙骨间加横档，直接把设备固定到木头上。

**板书笔记**：
- 判断墙体：实心 ↔ 空心
- 石膏板固定件承载（kgf≈10N）
  - 螺纹/翼型：<10 kgf
  - 空腔/肘节：≤20 kgf
  - 天花板：×0.8；优先设横档
- 防旋齿防止锚固件转动

## 第三部分：支撑间距与承载计算

**视觉计划**：
- 图表：套筒锚承载能力与直径、深度的关系曲线
- 3D模型：电机底座上的锚栓布置，显示间距标注
- 动画：振动导致普通膨胀锚逐渐松脱

**解说词**：
固定件的承载能力不仅取决于自身，还与安装方式和间距有关。套筒锚装在垂直墙上时，直径越大承载越高；但装在天花板上时，主要看埋入的深度。对于像水泵或风机这样的振动设备，化学锚是必备的，因为振动会使普通膨胀锚慢慢松动。

在设计固定方案时，我们要确保安全系数至少为4比1，也就是说，如果设备重100公斤，固定系统整体至少要能承受400公斤。固定点要均匀排布，避免局部过载。

**板书笔记**：
- 套筒锚：墙（直径定承载）、天花板（深度定承载）
- 动载荷 → 化学锚
- 安全系数 ≥ 4:1
- 合理间距：约10–15倍锚栓直径

## 第四部分：安装质量检查

**视觉计划**：
- 工人使用扭矩扳手检查螺栓，表盘读数特写
- 工人用小锤轻敲锚栓周围，侧耳倾听
- 检查表示例，填写项目

**解说词**：
安装完成不代表工作结束。我们必须仔细检查每个固定点。首先看固定件是否垂直、有没有歪斜，基材有没有裂纹。然后用扭矩扳手抽查，确保紧固力符合制造商建议。对于化学锚，一定要查看时间，确认树脂已经完全固化才能加载。最后，把所有检查结果记录在案，任何问题都要报告给持证电工。

记住，安装质量检查是我们的职业责任，它直接关系到用电安全。

**板书笔记**：
- 检查步骤：目视 → 扭矩 → 敲击 → 时间确认
- 化学锚：等待固化（≥30分钟，依产品）
- 记录所有异常
- 最终由持证电工确认
