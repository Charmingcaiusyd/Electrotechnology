# Electrotechnology 课程知识点卡

本正式学习包以在线知识卡作为学生入口，不再包含旧版 3000 题库、各模块 quiz 或综合试卷。

## 学习入口

- `html/index.html`：S1–S10 完整课程知识卡，可离线打开。
- `html/cards-data.js`：卡片内容数据。
- `knowledge_cards_review.md`：课程范围、复核原则及需查现行规范的事项。
- `modules/S1` 至 `modules/S10`：课程讲义和视频脚本，供进一步学习。
- `../../pdf/Electrotechnology_教材全解_合订版.pdf`：合订教材全解。

## 卡片功能

- 1,187 张知识卡，标记“核心考点”或“细节知识”；S1–S6 分别为 138/518/130/105/93/101 张。
- 按模块、主题、重要程度及掌握状态筛选，并可搜索问题和答案。
- 记住/没记住/未刷状态保存在当前浏览器；可导出和导入进度 JSON。
- 复习范围可限定为遗忘卡，标记掌握后自动移出遗忘队列。

卡片来源标注课程模块或教材页，逐模块来源映射及审核边界见 `knowledge_cards_review.md`。S4–S6 的讲义与视频脚本已同步修订关键的图纸核验、测试安全、器件额定和电机启动误导点。规范数值、产品额定值及安装条件依地区、版本和现场而变，须复核当前适用标准及制造商资料。
