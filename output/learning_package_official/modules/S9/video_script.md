# 视频脚本：导管、线槽与布线安装

## S9.1 导管系统

### 画面计划
- 开场：展示工地现场，电工正在开槽布管，出现标题“导管系统 (Conduit Systems)”。
- 特写：不同颜色的UPVC导管（灰、橙）及配套弯头。
- 白板讲解：画出导管等级对应表。
- 实操演示：切割、倒角、溶剂粘接的特写镜头。
- 虚拟动画：导管内部电缆被毛刺划伤的对比。
- 现场：用水平尺检查坡度、在低点钻孔。

### 旁白
【旁白开始】
在澳大利亚，电工安装布线外壳属于法定电气工作，必须持证并在有执照人员监督下进行。本模块仅作技能培训使用，实际作业务必依据当前AS/NZS 3000标准。
导管系统的首要任务是保护电缆免受机械损伤和环境侵蚀，并为日后的维护升级留出空间。请看，这三种颜色代表不同的强度等级：灰色轻型仅允许凿墙暗埋；灰色中型是地上最常用的，也可浇筑在混凝土板内；橙色重型专门用于地下直埋（第212页）。
现在，我们来进行标准操作。第一步：用导管割刀或细齿锯垂直切割。切记戴上侧面防护眼镜！切完后，一定要用绞刀去除内部毛刺，再做一个轻微的倒角——这能防止锋利边缘刮伤电缆绝缘（第212页）。
接下来是溶剂粘接。这是一种化学融合，可不是普通胶水。把溶剂水泥均匀涂在管端和管接头内壁，插进去后顺时针转四分之一圈，保持十几秒钟。看，接头已经能初步受得住力。不过要完全固化得24小时，期间应避免承受外力（第212‑213页）。
粘接好的导管该怎么走呢？基本原则：水平、垂直，顺着建筑线条。尽量减少弯头，使用大弧度转弯。在所有出线盒、开关处都要留够操作空间。别忘了，先穿钢丝引线再封管口，防止进灰。
我们还必须考虑排水。如果管内可能会凝露或进水，整段朝一个方向倾斜，在最低位置钻一个5毫米的小孔——这叫泄水孔。地下无法自然排水的，就要像这样搞一个排水小井（第214页）。

【暂停提问】

### 白板注释
- 导管等级：Light duty grey (墙内) / Medium duty grey (地上/板内) / Heavy duty orange (地下)
- 切割三步骤：切 → 去毛刺 → 倒角
- 粘接要点：涂匀 → 转1/4圈 → 保持15秒
- 排水：坡度 + 低点泄水孔

## S9.2 布线外壳

### 画面计划
- 对比展示：刚性钢管、柔性金属管、PVC线槽、电缆梯架、穿孔托盘。
- 动画：冲击测试，不同外壳对内部电缆的保护效果。
- 场景：化工厂腐蚀管路、沿海锈蚀支架、老鼠啃咬的PVC管。
- 实操：用游标卡尺测量线槽内预留空间。
- 白板：列出各种外壳的适用/不适用环境。

### 旁白
我们把导管、线槽、梯架统称为布线外壳。它们不只是个罩子，更是整个电气装置的安全屏障（第212页）。选错类型，后果可能很严重。
比如在充满化学溶剂的地方安装了普通UPVC管，看看这画面——管子都酥了，电缆也暴露出来。同样，沿海盐雾下，普通钢管半年就能锈透！所以一定要照着规范选材（第213‑214页）。
选择外壳时，要实地勘查四个风险：化学腐蚀、紫外线、动物啃咬以及机械撞击。像这种室外太阳直射的墙面，用了普通的灰色管就得刷上一层浅色丙烯酸漆，或者干脆直接选标有“T”的防紫外线管（第213页）。
工业厂房里电缆成堆，线路经常变动，这时候梯形支架或穿孔托盘就非常合适——散热好，扩容也方便，只要在添加电缆时注意别超过承载量就行。但所有金属外壳都必须可靠接地，保持整个通路导通，哪怕只是搭接两块梯段。（第212‑213页）
最后别忘了，外壳不是刚刚好就行，要给未来的可能增加回路留出余地。经验法则：留出约30%的备用空间（第212页）。

### 白板注释
- 外壳类型：Rigid steel / Flexible metal conduit / PVC trunking / Cable tray / Ladder
- 禁选案例：UPVC vs 酯类 / Steel vs 沿海 / ABS vs 有机溶剂
- 安全要点：金属外壳连续性接地
- 扩容：预留30%空间

## S9.3 弯管与支撑

### 画面计划
- 演示：徒手弯管失败的褶皱特写 vs 用弹簧均匀弯曲的平滑管段。
- 分屏：不同管径的水平、垂直距离标记，用动画加标尺显示鞍夹间距。
- 现场：在砖墙上弹线、画定位标记，用电钻打孔固定鞍夹。
- 特写：弯头两侧双鞍夹的安装。
- 白板：总结间距表格。

### 旁白
弯曲导管看起来简单，但要做得不伤管、不伤线，就得掌握要领。直接上手掰，管子一扁，内壁就起皱，电缆穿都穿不过去。正确做法是，把弯管弹簧放进需要弯曲的位置，然后用大腿或弯管器均匀使劲。记住一个原则：弯曲半径不能太小，最小应该是电缆直径的6倍（第214页）。
支撑也是关键。如果鞍夹隔得太远，导管会慢慢往下坠，接头就绷开了。标准要求：20或25毫米的管子，在水平方向每900毫米必须有一个鞍夹；32毫米以上的管子可以放宽到1.2米。垂直方向，所有管子统统不超过1.2米。而且每个弯头、每个三通出口150到200毫米之内，一定要两边都加鞍夹（第213‑214页）。
现在就操作一遍：量好距离，铅笔做记号，钻孔后塞胶粒，然后上鞍夹。螺丝拧到管夹刚好咬住管子就行，别死命扭，会把UPVC管挤裂。
暂停一下，思考：如果导管跨过很大一个洞，没有支撑点怎么办？
【暂停提问】

### 白板注释
- 弯管工具：弹簧（内部/外部）或弯管机
- 鞍夹最大间距：20‑25mm管水平900mm，32mm+水平1.2m，垂直1.2m
- 弯头/接头处：<150‑200mm内两边各一个鞍夹
- 力矩提示：螺丝适度拧紧

## S9.4 安装路径规划

### 画面计划
- 动画：三维建筑内导管与其他管道的冲突演示，然后重新规划优化走向。
- 现场：用卷尺和水平仪在墙面弹线。
- 模拟：长直线段夏日暴晒下导管膨胀顶开接头的后果，然后加入补偿节。
- 实操：用软粘泥封堵管口、制作标签绑在管端。
- 全景：已完成的整齐管道系统，排水孔低点可见。

### 旁白
真正开始铺管前，先绕着工地走三遍，好好规划路线。目标：尽量直、少转弯，还要避开其他水管、煤气管。万一躲不开，至少保持300毫米间距，燃气管就得500毫米以上（第213页）。
你看到这条长走廊吗？你要是直接拉一根30米的直管，夏天一晒，它会因为热胀伸长而扭弯，甚至把接头撑开。解决办法是每6米左右装一个补偿接头，给它伸缩的余地。
另外，规划时就要想好排水。每一段可能积水的地方，我们就设计一个坡度，保证水流到最低点，然后在这里钻眼。地下管就更复杂些，得在低洼处做个过滤坑。
开始干活前，先把所有管口临时封堵，防止水泥渣、虫蚁爬进去。每完成一段，挂上标签，写下回路编号。最后全部安装完，用水平仪和线垂复查一遍，确保横平竖直，排水坡向正确，才算合格。

【暂停提问】

### 白板注释
- 路径原则：沿建筑线 / 远离其它服务管道（≥300mm水管，≥500mm燃气）
- 热胀冷缩：>6m直线加补偿节
- 排水措施：向低点倾斜，钻5mm孔或做排水井
- 施工封口：临时用粘泥堵管，系识别标签
