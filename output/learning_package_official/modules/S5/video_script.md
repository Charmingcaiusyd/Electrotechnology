# 视频脚本：继电器与接触器控制

## S5.1 控制回路基础

### 旁白 (Narration)
大家好，欢迎来到继电器与接触器控制模块。今天我们从控制回路的基础开始。  
你可曾想过，为什么工厂里的按钮用低压电，却能控制几百伏的电机？秘密就在于控制回路与功率回路的分离。  
看这个图：左边是24V直流控制回路，有一个按钮和继电器线圈；右边是230V交流功率回路，有触点和一个灯。按下按钮，线圈得电，电磁力闭合触点，灯亮。按钮只是控制线圈，线圈再去控制大负载。这样既安全又方便。  
注意所有触点符号都画在它们的*常态*——没电时的状态。NO常开，NC常闭。记住这些，是读懂图纸的第一步。

- 展示一个简化电路图（图6.5），高亮控制回路和功率回路。

### 板书笔记 (Board Notes)
- 控制回路 = 低压 + 按钮 + 线圈
- 功率回路 = 高压 + 触点 + 负载
- 符号常态 = 未通电状态

## S5.2 继电器线圈与触点

### 旁白
现在，我们来放大继电器本身。这是一个典型的八脚继电器。去掉外壳，你会看到线圈、衔铁和几组触点。  
当线圈通电，铁心被磁化，吸引衔铁下压，原来接通的NC触点会断开，断开的NO触点会闭合。我们听到的“咔嗒”声就是触点转换。  
线圈和触点的标号有讲究：线圈叫K1，它的触点就叫K1.1、K1.2…这样在电路图上很容易分辨。  
别忘了，还有干簧继电器，它的触点密封在玻璃管里，开断非常快，但只能用于很小的电流。  
动手时，先用万用表找出线圈端子，然后验证NO和NC触点的常态。给线圈上电，再量一遍，确认它们翻转了。

### 视觉计划
- 解剖一个透明的继电器，镜头特写线圈、衔铁、触点。
- 在屏幕上叠加动态箭头，显示磁路和运动方向。
- 对比机电继电器和干簧继电器实物。
- 演示用万用表测量线圈电阻和触点通断。

### 板书笔记
- 线圈得电 → 衔铁吸合 → NO 闭合 / NC 断开
- 引脚识别：线圈通常位于底座中心位置或标记“+”“-”/“A1”“A2”

### 暂停问题
“继电器底座上标记着‘A1’‘A2’，它们是什么端子？在未上电时，如果‘11’和‘14’导通，这是NO还是NC触点？请思考并回答。”

## S5.3 接触器主触点/辅助触点

### 旁白
当负载是电机时，普通继电器往往不够用。这时候就需要接触器——一种重载继电器。  
看这个接触器，它有三组大大的主触点，用来通断电机的大电流；顶部还有几组小的辅助触点，用于控制回路。  
与普通继电器不同，主触点上装着灭弧罩，能快速熄灭分断时产生的电弧，保护触点。  
选择接触器时，一定要核对铭牌：线圈电压是多少？主触点的额定电流是否满足电机启动要求？  
在实训中，你要能拆开接触器，找出线圈、主触点和辅助触点，并测量它们的动作。记住，辅助触点用来做自锁、互锁，千万不可用来直接带电机！

### 视觉计划
- 展示一个拆开的接触器，镜头分别指向主触点、辅助触点、灭弧罩、线圈。
- 慢动作动画显示衔铁带动主触点闭合，电弧在灭弧罩内消散。
- 展示接触器铭牌，解说电压、电流、AC-3等参数。

### 板书笔记
- 主触点：大电流，带灭弧，接负载
- 辅助触点：小电流，用于逻辑，接控制回路
- 铭牌必读：线圈电压、主触点额定电流、负载类型

“如果你有一个24V直流信号，但接触器线圈是230V交流的，该怎么办？请设想一种方案。”

## S5.4 自保持与互锁

### 旁白
最后，我们来学习两种最重要的控制逻辑：自保持和互锁。  
自保持回路也叫自锁。看这个启动/停止电路：按下启动按钮，接触器线圈得电，它的辅助触点闭合，绕过了启动按钮；即使你松开按钮，电流继续流过辅助触点，保持线圈吸合。这就是自锁。要停止？按下停止按钮，线圈失电，自锁触点断开。  
自锁还提供了*欠压保护*：一旦停电，线圈释放；再来电时，因为启动按钮没按下，接触器不会自行启动。安全！  
互锁用于不允许同时通电的场合。比如电机正反转控制：KM1和KM2不能同时吸合，否则短路。所以，我们将KM1的常闭辅助触点串联在KM2线圈回路里，同样KM2的常闭也串在KM1回路里。这样一个吸合，就会断开另一个的电路。  
接线时小心不要接错：启动按钮是NO，停止按钮是NC，自锁触点也是NO。互锁触点则是NC。  
现在，我们动手搭建并验证这些电路。

### 视觉计划
- 先用梯形图展示标准启/停电路，动态显示启动→自保持→停止的过程。
- 再用动画展示两个接触器互锁：按下KM1按钮，KM1吸合，KM1的NC断开，KM2按钮无效。
- 最后展示断电/恢复的欠压保护：灯不亮，必须重新按启动。

### 板书笔记
- 自锁：NO辅助触点并联于启动按钮
- 停止按钮必须用NC
- 互锁：将对方接触器的NC辅助触点串联到自己的线圈回路

“如果一个学徒将停止按钮接成了NO触点，会发生什么？你能在电路中快速找到这个错误吗？”
