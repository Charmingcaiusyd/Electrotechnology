# 模块 S1：安全隔离与风险控制

## 1. 风险管理流程

### 学习目标
- 能描述并执行电气工作的风险评估流程。
- 理解风险评估中记录与沟通的重要性。

### 关键术语
- 危害（Hazard）：可能造成伤害的来源（如电能、高处作业）。
- 风险（Risk）：危害导致伤害的可能性和严重程度。
- 风险评估（Risk Assessment）：识别危害、分析风险并决定控制措施的过程。
- 控制措施（Control Measures）：消除或降低风险的方法。

### 原理
风险管理是一个遵守健康安全义务、必须贯穿电气企业文化的咨询过程（Study Pack pp.4–5；Book 55EP）。它包括四个核心元素：**识别危害、评估风险、控制风险、审查控制措施**（Figure 2.1）。在工作现场，风险评估必须针对具体任务定制；关键要判断危害是否有足够的防护。过程需记录，以证明采取了系统方法。

### 监督下的实践工作流程
1. **定义关系**：确认自身是否经过适当培训、具备相关设备经验；识别所有利益相关者（同事、操作员等）并建立沟通。
2. **发现风险**：现场巡视，列出可能影响健康安全的事件（发生了什么、怎么发生、谁可能受伤）（Study Pack pp.4–5；Book 55EP–56EP）。
3. **风险分析**：按后果严重度与可能性将风险分类（高：可能致命；中：重伤；小：轻伤），评估现有控制是否足够（Study Pack p.5；Book 56EP）。
4. **风险应对**：选择选项——规避风险、降低可能性、减少影响，并制定行动方案（Study Pack p.5；Book 56EP）。
5. **实施与监督**：指定有能力的人员负责，观察工作过程以防意外改变风险等级。
6. **审查与记录**：工作完成后审查措施有效性，记录所有步骤及关键发现（包括如何识别、评估、控制）（Study Pack pp.5–6；Book 56EP–57EP）。

### 常见错误
- 忽略低概率但后果严重的风险。
- 风险评估未记录或记录不完整。
- 未与相关人员协商，独自决定控制措施。
- 工作完成后不审查控制措施的有效性。

### 检查问题
1. 列出风险管理过程的四个关键步骤。
2. 为什么风险评估的第一步是确认自身与任务的关系？
3. 给一个电气风险分类的例子，并说明可能的后果。
4. 风险应对的三种选项是什么？
5. 为什么记录风险评估很重要？

## 2. 危害识别与控制层级

### 学习目标
- 能够识别电气工作场所中的常见危害。
- 理解并应用控制层级来管理风险。

### 关键术语
- 危害识别（Hazard Identification）：系统性地发现工作场所中可能导致伤害的来源。
- 控制层级（Hierarchy of Control）：从最有效到最无效的顺序排列的控制措施（如消除、替代、工程控制、行政控制、PPE）。
- 可能性（Likelihood）：危害导致事件发生的概率。
- 后果（Consequence）：事件发生后的严重程度。

### 原理
危害与风险不同：**危害**是具有造成伤害潜力的物体、情况或能量（例如裸露导线），而**风险**是伤害发生的可能性与严重度。危害可能来自工作场所设计、任务、设备、物质等（Study Pack p.7；Book 58EP）。只有识别了危害才能控制。控制层级（Hierarchy of Control）是选择控制措施的指导原则，优先考虑消除危害（如断电），最后才是个人防护装备（PPE）。风险评估表（Figure 2.3）要求应用该层级（Study Pack p.6；Book 57EP）。

### 监督下的实践工作流程
1. **现场巡视与检查**：使用危害检查表（示例：Figure 2.4）列出所有潜在危害，例如电击、眼睛伤害、振动等（Study Pack p.5；Book 56EP）。
2. **分析风险**：对每个危害，评估其暴露等级和后果，填写风险评估表（Figure 2.3）。
3. **按层级选择控制**：考虑消除（如能否断电？）、替代（低电压工具）、工程措施（绝缘、隔离）、行政措施（程序、培训）、PPE（手套、护目镜）。
4. **记录与审批**：将评估和控制措施记录在表格上，获取授权人员批准。
5. **实施与监督**：执行控制措施，通过工具盒会议沟通，并在工作中监督。

### 常见错误
- 匆忙开始工作，跳过系统的危害识别。
- 过度依赖PPE而忽视更有效的消除或工程控制。
- 未考虑所有可能受影响的人员（如旁观者）。
- 风险评级后不重新评估新控制的有效性。

### 检查问题
1. 解释“危害”与“风险”的区别。
2. 列出电气工作场所中危害的三个主要来源。
3. 描述控制层级中最有效到最不有效的顺序。
4. 为什么必须记录风险评估？
5. 给出一个例子，说明电气任务中如何使用检查表识别危害。

## 3. 安全隔离与锁定挂牌

### 学习目标
- 能按正确顺序执行电气隔离程序。
- 理解锁定/挂牌（Lockout/Tagout）的重要性。

### 关键术语
- 隔离（Isolation）：断开所有电源并与带电部分保持安全距离。
- 锁定（Lockout）：用锁具固定断开装置，防止意外合闸。
- 挂牌（Tagout）：在隔离点悬挂警示标签，注明操作人等信息。
- 验电（Proving Dead）：用校验过的仪器确认电路无电。

### 原理
在对电气设备或电路进行作业前，必须将其与所有供电电源隔离，并采取锁定挂牌措施，经验证确认无电后才能开始工作。这是风险控制层级中“消除”危害的关键实践。任何隔离程序都应遵循标准操作步骤，并由持证人员监督。最终符合性必须参照现行标准（如AS/NZS 3000）。

### 监督下的实践工作流程
1. **识别电源**：查阅图纸，确认所有可能的供电路径（包括备用电源）。
2. **断开并锁定**：操作开关或断路器断开电源，使用个人锁具锁定在OFF位置。
3. **挂牌**：在锁上悬挂“禁止合闸，有人工作”标签，并填写日期、姓名。
4. **验电**：用已知良好且经校验的电压测试仪，在隔离设备上先测带电电路验证仪器，再测已断开触点确认无电。
5. **工作**：在许可后方可开始作业。
6. **恢复供电**：工作完成、工具清场后，由负责人解锁、摘牌、合闸。

### 常见错误
- 忘记锁定控制开关，仅靠挂牌。
- 验电前未测试验电器的功能。
- 未通知所有受影响人员隔离操作。
- 使用不合格的锁具或标签。

1. 为什么隔离后必须锁定和挂牌？
2. 列出电气隔离的五个关键步骤。
3. 验电之前为什么要先在已知带电电路上测试验电器？
4. 谁有责任移除锁定/挂牌？
5. 恢复供电前应确认什么？

## 4. 测试仪器与低压作业边界

### 学习目标
- 能选择合适的测试仪器并正确使用。
- 知晓低压作业的安全边界和带电作业限制。

### 关键术语
- CAT等级（CAT Rating）：仪表耐受瞬态过电压的能力分类。
- 安全边界（Safe Approach Distances）：防止电弧和意外接触的保持距离。
- 带电作业（Live Work）：在未隔离的带电部分上或其附近进行的作业。
- 校验（Calibration）：确认仪器测量准确的程序。

### 原理
测试是电气工作安全的基础，但错误的仪器使用可能导致伤害。必须使用具有正确CAT等级的仪表，并遵守低压安全边界（如AS/NZS 3000中规定的距离）。只有经特殊许可和培训的人员才可进行带电作业；学徒必须在无电环境下工作。任何测试前应检查仪器外观和校验日期，并在已知带电电源上验证功能。

### 监督下的实践工作流程
1. **仪器检查**：检查外观无破损，校验标签在有效期内。
2. **选择仪器**：根据被测电路类别和电压选择适当CAT等级的万用表或测试仪。
3. **功能验证**：在已知带电的插座或电源上测试仪器，确认读数正确。
4. **测量**：使用“一手操作”技巧减少电击风险，保持安全边界。
5. **使用后存放**：关闭仪器，清洁并在安全条件下存放。

### 常见错误
- 使用电流档测电压，烧毁仪表。
- 忽略仪器校验状态，使用不准确的仪表。
- 测试前不验证仪器功能，导致误判无电。
- 超出仪器额定值测量（如CAT III用于CAT I环境问题不大，但反过来危险）。

5. 说明低压作业的安全边界一般距离（提示：联系当地规程）。
